# Краткий отчёт в Typst

Основа: modern-g7-32 0.2.0, ГОСТ 7.32-2017. Именно этот пакет используется рекомендованным методичкой репозиторием https://github.com/e1turin/typst-docs-template.

Копия шаблона сохранена в `vendor/modern-g7-32`, лицензия и сведения об авторах сохранены. Исходники шаблона не изменены. Для краткого лабораторного отчёта добавлен титульный лист в `title.typ`; содержание и автоматические разрывы разделов отключены. Поля, основной шрифт 14 pt, отступ 1,25 см и межстрочный интервал взяты из шаблона; уменьшены интервалы между абзацами и заголовками. ФИО, группа и преподаватель указаны в `title.typ`.

Из корня лабораторной:

```sh
bash scripts/build-report.sh
```

Результат: `output/pdf/report-gost.pdf`. Таблица и отношения времён читаются из `results/summary.json`; Компактные русскоязычные SVG-графики пересоздаются скриптом `scripts/report_figures.py` по CSV новой серии. Для этого используется уже подготовленное Python-окружение `out/venv`. Текст описывает серию 05.10.2026. После нового эксперимента следует проверить датированные сведения и численные пояснения.

Обновление статистики: `out/venv/bin/python scripts/analyze.py`. Этот скрипт сохраняет только данные и графики.

Генерация подробного Markdown и PDF отдельно: `out/venv/bin/python report/generate.py`. Используются готовые `summary.json`, `diagnostics-summary.json`, метаданные и графики.

Короткий ГОСТ-отчёт собирается командой выше; подробный генератор для него не требуется.
